## Kroki

Kroki 是一个开源的统一 API 服务，它能把你用文本编写的图表描述代码，实时转换成 PNG、SVG 等格式的图片。简单来说，就是"用代码画图"。

它的核心功能和典型应用场景如下：

核心功能：支持超20种图表库：Kroki 就像一个"图表转换器"，把多种图表库整合在了一个统一的接口下。这意味着你只需要学会用文本描述图表（如 Mermaid、PlantUML），剩下的转换工作交给 Kroki 即可。它支持的类型非常丰富，常用的包括：
- Mermaid：流程图、时序图、甘特图
- PlantUML：UML类图、时序图、用例图
- GraphViz：复杂的网络拓扑和依赖关系图
- Excalidraw：手绘风格的白板图
- 以及 BPMN、D2、DBML 等众多格式

> [Kroki](https://kroki.io/)


## Mermaid

Mermaid 是一个开源的 JavaScript 库，它的核心理念是让你用类似 Markdown 的纯文本语法来定义和生成图表。你可以把它理解为"画图界的 Markdown"——就像用 `#` 表示标题、`-` 表示列表一样，Mermaid 让你用特定的文本语法来描述图表结构。

它的最大特点是文本即图表，这使得它非常适合在技术文档、代码库和协作工具中使用。

> [Mermaid](https://mermaid-js.github.io/mermaid/#/)


## PlantUML

如果说 Mermaid 追求的是轻量、易读，像"画图界的 Markdown"；那么 PlantUML 就是一位严谨、强大的"建模专家"。

它是使用最广泛的开源 UML 绘图工具之一，核心价值在于用文本描述语言来绘制专业、复杂且规范的 UML 图。

> [PlantUML](https://plantuml.com/zh/)
