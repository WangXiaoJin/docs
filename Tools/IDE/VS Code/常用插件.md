# VS Code 常用插件

## 1. Java

### 1.1 Extension Pack for Java

`Extension Pack for Java` 是一个常用扩展集合，可以帮助你在 Visual Studio Code 中编写、测试和调试 Java 应用程序。

- **`Language Support for Java(TM) by Red Hat`** - 代码导航、自动补全、重构、代码片段

- **`Debugger for Java`** - 调试功能

- **`Test Runner for Java`** - 运行和调试 JUnit / TestNG 测试用例

- **`Maven for Java`** - 集成Maven构建能力

- **`Gradle for Java`** - 查看 Gradle 任务和项目依赖、编写 Gradle 文件、通过 Gradle Build Server 导入 Gradle 项目

- **`Project Manager for Java`** - 管理 Java 项目、引用的库、资源文件、包、类及类成员

### 1.2 Extension Pack for Java Auto Config

`Extension Pack for Java Auto Config` 是一个“一站式”的 Java 开发环境配置包，其核心功能是**自动检测、配置和管理 JDK**，让你无需手动设置就能在 VS Code 中直接开发 Java 和 Spring Boot 项目。

- **`Extension Pack for Java`** - 参考上一个插件集

- **`Spring Boot Extension Pack`** - Spring Boot开发插件集
  
  - **`Spring Boot Tools`** - 提供用于开发和排查 Spring Boot 应用程序的 IDE Java 工具支持，支持编辑 Spring Boot 应用程序的配置文件。
  
  - **`Spring Initializr Java Support`** -  通过 Spring Initializr API 快速生成 Spring Boot Java 项目。
  
  - **`Spring Boot Dashboard`** - 在侧边栏中提供了一个资源管理器，可集中查看工作区中所有的 Spring Boot 项目，支持快速启动、停止或调试项目。

- **XML**- XML 语言支持

- **Code Spell Checker** - 源代码拼写检查器

- **Live Server** - 启动本地开发服务器，支持静态和动态页面的实时重载

- **Trailing Spaces** - 高亮尾部空格，并可一键删除

- **indent-rainbow** - 让缩进更易于阅读

- **Rainbow CSV** - 高亮 CSV 和 TSV 文件，支持运行类似 SQL 的查询

### 1.3 Maven Helper

专业的 Maven 依赖分析工具，旨在填补 VSCode 生态中的空白，大幅提升您的开发效率。

### 1.4 Maven dependency explorer

**Maven dependency explorer** 是一个让你通过直观的**树形视图**查看 Maven 项目依赖关系，并支持过滤和冲突检测的插件

### 1.5 Super Mybatis

Super Mybatis 弥补了在 VSCode 下没有高效、功能强大的 Mybatis 辅助功能插件，该插件当前还处于预览版本，特性与BUG会持续修复，请放心安装，让你拥有无比强大的 Mybatis 增强功能。

## 4. 杂项

- **GitLens — Git supercharged** - 将 Git 的**代码溯源、历史可视化、PR协作和AI辅助**深度集成到编辑器中的强大扩展

- **EditorConfig** - 自动应用项目里 `.editorconfig` 文件定义的代码风格，保证团队协作时编码规范的一致性

- **Container Tools** - VS Code 官方推出的容器开发扩展，提供**多运行时支持、可视化容器管理、智能配置编辑和AI集成**，将容器构建、管理和调试全流程无缝融入编辑器

- **Git Graph** - 将仓库提交历史以**交互式图形**直观呈现的 VS Code 扩展，让你能清晰看到分支、合并和提交在时间线上的演变关系，并直接在图面上执行 Git 操作

- **Git History** - 将 Git 的日志查看、搜索、比较等操作，以可视化、结构化的方式呈现

- **gitignore** - 生成、编辑和管理 `.gitignore` 文件

- **Markdown All in One**  - 功能全面的 Markdown 增强插件，通过提供自动生成目录、快捷键格式化、列表编辑与自动补全等功能，将 VS Code 打造成一个高效流畅的 Markdown 写作环境

- **Markdown Preview Enhanced**  - 将 Markdown 预览体验推向极致的插件。它不仅仅是一个预览工具，更是一个能让你在 Markdown 中运行代码、绘制专业图表、创建演示文稿，并将其导出为 PDF/HTML/Word 的多功能文档工作台

- **Prettier - Code formatter** - 代码格式化工具，它能通过解析代码语法，自动将多种语言（如 JavaScript、HTML、CSS 等）的代码重新排版为统一风格，从而让你彻底摆脱手动调整缩进、空格、分号等格式细节的繁琐工作。

- **Thunder Client**  - 是一款轻量级、完全基于本地存储的 REST API 客户端，让你在 VS Code 中通过图形界面直接发送 HTTP 请求、管理接口集合并进行可视化测试

- **Todo Tree** - 自动扫描项目中所有 `TODO`、`FIXME` 等注释标签，并将其以**树形结构清晰展示在侧边栏**的 VS Code 插件，方便你集中追踪和管理代码中的待办事项

- **Error Lens**  - 将代码中的错误、警告和提示，以醒目的内联高亮方式直接显示在**当前代码行末尾**，并在编辑器右侧缩略图区域标注问题位置的插件，让你无需翻看底部的“问题”面板，就能在编码时即时发现并修复问题。

- **SonarQube for IDE**  - 编码时实时高亮显示代码中的质量、安全漏洞和坏味道等问题，并提供快速修复方案与详细的修复引导，帮助你在提交代码前即时修正

- **DBCode - SQL & Database Client for VS Code** - 全能的数据库客户端
